系統架構說明

本網站實作 資料編輯與紀錄模組 與 使用者操作與資料反饋模組（Node.js 後端），並連接 MongoDB 以儲存設定與研究資料。IVR 教室互動模組（Unity）可透過 API 讀寫資料，本處不實作 Unity 端。

  • 編輯功能：個人資料、量表問卷、Prompt 設定（虛擬學生人格特質、互動風格、情緒回應規則等）
  • 紀錄功能：統一介面寫入個人資料、問卷、情緒回饋、決策歷程、生理指標（瞳孔、GSR、心率）與歷程資料，均附時間戳記
  • 操作與反饋：情緒標註、多模態指標反饋、情緒察覺反思，並提供資料供 ChatGPT 分析
