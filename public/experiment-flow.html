實驗流程編輯

設定實驗步驟順序，每一步可指定 Survey key、指導語 key 或自訂 HTML 頁面。

首頁 編輯功能 紀錄功能 操作與反饋 量表編輯 指導語設定 實驗流程編輯

流程步驟（預設流程 default）

每個步驟的 步驟 key 會對應網址 `/experiment/{步驟 key}`。
- 類型為 survey 時，請在「對應 key / 路徑」填入量表或情境的 key。
- 類型為 instruction 時，填入指導語的 key（`Instruction.key`）。
- 類型為 custom 時，填入自訂 HTML 路徑，例如 `/custom/intro.html`。

順序 步驟 key 名稱（顯示用） 類型 對應 key / 路徑 操作
執行時行為說明： - 入口 `/experiment` 會自動導向預設流程（flowKey = default）的第一個步驟 `/experiment/{步驟 key}`。 - 實驗頁 `/experiment/{步驟 key}` 會呼叫 `/api/experiments/steps/{key}` 取得設定： - type = "instruction" 時，可再呼叫 `/api/instructions/by-key/{refKey}` 取得指導語 HTML。 - type = "survey" 時，前端/Unity 可依 `refKey` 決定載入哪個量表或情境。 - type = "custom" 時，可透過 `customPath` 載入自訂頁面。
