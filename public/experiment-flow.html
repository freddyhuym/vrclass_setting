流程步驟（預設流程 default）

使用 上移／下移、刪除、新增、載入本頁 後，會依順序自動將步驟 key 與顯示名稱定為 step1、step2、… 與網址 /experiment/step1 等一致。

每個步驟的 步驟 key 會對應網址 `/experiment/{步驟 key}`。
- 類型為 survey 時，請在「對應 key / 路徑」填入量表或情境的 key。
- 類型為 instruction 時，填入指導語的 key（`Instruction.key`）。
- 類型為 custom 時，將自訂 HTML 放在專案 public/custom/ 下，路徑如 /setting/custom/檔名.html，與 gptfeedback 分開。
- 類型為 gptfeedback 時，頁面放 public/gptfeedback/，路徑如 /setting/gptfeedback/檔名.html，並可展開「編輯 GPT 提示詞」輸入給模型用的內容（執行實驗時會寫入 sessionStorage 供內嵌頁讀取）。

順序 步驟 key 名稱（顯示用） 類型 對應 key / 路徑 （gpt：路徑＝.html 網址，提示只寫在展開的 GPT 提示框） 操作
執行時行為說明： - 入口 `/experiment` 會自動導向預設流程（flowKey = default）的第一個步驟 `/experiment/{步驟 key}`。 - 實驗頁 `/experiment/{步驟 key}` 會呼叫 `/api/experiments/steps/{key}` 取得設定： - type = "instruction" 時，可再呼叫 `/api/instructions/by-key/{refKey}` 取得指導語 HTML。 - type = "survey" 時，前端/Unity 可依 `refKey` 決定載入哪個量表或情境。 - type = "custom" 時，以 `customPath` iframe 載入（建議 `/setting/custom/...`）。
- type = "gptfeedback" 時，以 `customPath` iframe 載入（必須是 `/setting/gptfeedback/xxx.html` 這類路徑）；給模型看的長段文字只填在「編輯 GPT 提示詞」(gptPrompt)。送後端 GPT 與綜合回饋的 uid／prompt 皆由內嵌頁 POST /api/gpt-vr/analyze 的 JSON body 傳出，與網址列的 /experiment/step3 之 step key 無關。若把提示詞誤貼在「路徑」欄，會導致頁面網址錯亂。內嵌網址並帶 ?gptStep={步驟key} 供內嵌頁讀 sessionStorage 內的提示。
